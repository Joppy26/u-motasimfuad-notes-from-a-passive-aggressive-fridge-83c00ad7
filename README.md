## What it does

`main.ts` writes one single-line note from a smart fridge to its owner to `/output/entry.txt`: a dry, petty, specific message the fridge would leave on its door screen, smug about its door sensors and the yogurt that expired while its owner stood there deciding nothing.

## Run

```sh
node main.ts
```

Deterministic: every run writes the exact same note, no network, no randomness, no input.
